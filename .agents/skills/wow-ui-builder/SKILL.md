# WoW UI Builder Skill

This skill provides the guidelines and standard practices for building authentic World of Warcraft Classic/Standard UI Panels. It focuses on using built-in UI textures, frame structures, and backdrops to ensure custom addon panels feel like they are a native part of the game (e.g., the Spellbook, Character Frame, and Talent Tree).

## 1. Frame Structure and Depth
Authentic WoW UI design uses multiple layers of frames to create structural depth.

- **Base Frame:** The main `Frame` widget should often inherit from standard templates such as `ButtonFrameTemplate` or `PortraitFrameTemplate`. 
  - **Note:** Templates like `ButtonFrameTemplate` automatically generate standard elements such as a close button, a portrait, a dark background (`$parentBg`), and an inset (`$parentInset`).
- **Scroll Frames:** If you need scrolling content, you **must** use the `<ScrollFrame>` tag (e.g. inheriting `UIPanelScrollFrameTemplate`). Do not use a standard `<Frame>` tag for scroll frames, as the `<ScrollChild>` tag will fail to render the content.
- **Backgrounds:** Classic UI elements are framed in wood or stone, with parchment backgrounds for text, descriptions, or lists.

## 2. Textures and Backdrops
To achieve the standard WoW aesthetic, utilize these commonly used textures and backdrops (found heavily in TRP3 and Standard WoW UI):

### Backdrops
Use `BackdropTemplate` in XML or `Mixin(frame, BackdropTemplateMixin)` in Lua, then set the backdrop.
Commonly used edge files for borders:
- `Interface\DialogFrame\UI-DialogBox-Border`
- `Interface\AchievementFrame\UI-Achievement-WoodBorder-Corner`
- `Interface\AchievementFrame\UI-Achievement-MetalBorder-Left`

### Background Textures
- **Parchment:** `Interface\AchievementFrame\UI-Achievement-Parchment` (Useful for text areas, descriptions).
- **Stone/Vault:** `Interface\GuildBankFrame\GuildVaultBG` (Useful for dark, structured panel backgrounds).
- **Marble/Solid:** `Interface\FrameGeneral\UI-Background-Marble`
- **Rock:** `Interface\FrameGeneral\UI-Background-Rock`

## 3. UI Component Templates
Always try to use built-in templates when creating common UI elements to preserve the authentic look and feel.

- **Close Buttons:** Inherit `UIPanelCloseButton`. Anchor it to the `TOPRIGHT` of your main frame.
- **Scroll Frames:** Inherit `UIPanelScrollFrameTemplate`. Add a `UIPanelScrollBarTemplate` if needed.
- **Buttons:**
  - Standard Action Buttons: Inherit `ActionButtonTemplate` or `UIPanelButtonTemplate`.
  - Close/Cancel: Inherit `UIPanelButtonTemplate`.
- **Tabs:** Inherit `CharacterFrameTabButtonTemplate` or `OptionsFrameTabButtonTemplate`.

## 4. XML vs Lua Creation
While frames can be created in Lua via `CreateFrame`, for complex, static UI panels that require precise layering and multiple textures (like a parchment background with metal joint overlays), **XML is preferred**. It provides a declarative, easy-to-read structure.

### Example XML Structure for a Panel
This example demonstrates how to place a parchment texture inside a `ScrollFrame` so it correctly overlays the default dark background generated by `ButtonFrameTemplate`.

```xml
<Frame name="MyCustomPanel" toplevel="true" parent="UIParent" enableMouse="true" hidden="true" inherits="ButtonFrameTemplate">
	<Size x="384" y="512"/>
	<Anchors>
		<Anchor point="CENTER" x="0" y="0"/>
	</Anchors>
    
	<Frames>
		<!-- 
		  ButtonFrameTemplate generates an inset called $parentInset.
		  We can anchor our ScrollFrame to it.
		-->
		<ScrollFrame name="$parentScrollFrame" inherits="UIPanelScrollFrameTemplate">
			<Anchors>
				<Anchor point="TOPLEFT" relativeTo="$parentInset" x="4" y="-4"/>
				<Anchor point="BOTTOMRIGHT" relativeTo="$parentInset" x="-26" y="4"/>
			</Anchors>
			<Layers>
				<Layer level="BACKGROUND">
					<!-- Parchment Overlay: Placed in the ScrollFrame so it renders above the $parentInset background -->
					<Texture name="$parentParchment" file="Interface\AchievementFrame\UI-Achievement-Parchment">
						<Anchors>
							<Anchor point="TOPLEFT" x="-4" y="4"/>
							<Anchor point="BOTTOMRIGHT" x="26" y="-4"/>
						</Anchors>
						<TexCoords left="0" right="0.65" top="0" bottom="0.9"/>
					</Texture>
				</Layer>
			</Layers>
			<ScrollChild>
				<Frame name="$parentScrollChild">
					<Size x="330" y="500"/>
					<!-- Content goes here -->
				</Frame>
			</ScrollChild>
		</ScrollFrame>
        
		<!-- Tabs -->
		<Button name="$parentTab1" inherits="CharacterFrameTabButtonTemplate" id="1" text="Tab 1">
			<Anchors>
				<Anchor point="TOPLEFT" relativePoint="BOTTOMLEFT">
					<Offset x="15" y="2"/>
				</Anchor>
			</Anchors>
		</Button>
		<Button name="$parentTab2" inherits="CharacterFrameTabButtonTemplate" id="2" text="Tab 2">
			<Anchors>
				<Anchor point="LEFT" relativeTo="$parentTab1" relativePoint="RIGHT">
					<Offset x="-15" y="0"/>
				</Anchor>
			</Anchors>
		</Button>
	</Frames>
	<Scripts>
		<OnLoad>
			tinsert(UISpecialFrames, self:GetName()); <!-- Allow closing with ESC -->
		</OnLoad>
	</Scripts>
</Frame>
```

## 5. Integration and Lua Logic
Separate UI manipulation from logic. In your Lua file, initialize the tabs and set up basic sounds:

```lua
MyCustomPanel:SetScript("OnShow", function(self)
    PlaySound(SOUNDKIT.IG_CHARACTER_INFO_TAB)
    if not self.initialized then
        -- Initialize standard tab functions
        PanelTemplates_SetNumTabs(self, 2)
        
        MyCustomPanelTab1:SetScript("OnClick", function() PanelTemplates_SetTab(self, 1) end)
        MyCustomPanelTab2:SetScript("OnClick", function() PanelTemplates_SetTab(self, 2) end)
        
        -- Automatically resizes the tabs to fit the text
        PanelTemplates_TabResize(MyCustomPanelTab1, 0)
        PanelTemplates_TabResize(MyCustomPanelTab2, 0)
        
        PanelTemplates_SetTab(self, 1)
        self.initialized = true
    end
end)

MyCustomPanel:SetScript("OnHide", function(self)
    PlaySound(SOUNDKIT.IG_MAINMENU_CLOSE)
end)
```
