Esta carpeta contendrá los archivos que manejarán el almacenamiento de datos de este FRAME. Todos los elementos guardados se harán en la variable GLOBAL del proyecto "GAC".

Los estores se crearan de la siguiente manera:

GAC.Stores.Template.VariableName = "Value"

Se puede crear archivos store para almacenar datos relacionados al frame. Con su propio estado Global sólo para el frame.
